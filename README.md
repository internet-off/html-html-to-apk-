# 📦 HTML to APK Builder & Signer

> [!WARNING]
> **ЭТО ТЕСТОВАЯ (DEV) ВЕРСИЯ!** Сборщик находится в активной разработке. Возможны баги и недоработки. Стабильная рабочая версия доступна в основной ветке `main`.

Полностью автономный браузерный конвейер для генерации, упаковки и подписания Android APK (`100% Pure JS` + `Web Crypto API`). Работает локально без серверов, Gradle, Android SDK и внешних библиотек.

## 🧩 Архитектура проекта (v13-dev)

Проект разделён на два независимых однофайловых инструмента:

### 1. `golem generator.html` — Android APK Shell Generator Pro
Синтезирует с нуля чистый базовый шаблон `template.apk` прямо в памяти браузера (бинарный `AndroidManifest.xml`, таблица ресурсов `resources.arsc`, скомпилированный байткод `classes.dex` и иконка):
- **Идентификация и SDK:** генерация уникального `Package Name`, настройка `app_name`, `versionCode`, `versionName`, `minSdkVersion` / `targetSdkVersion` и `allowBackup`.
- **Окно и UI:** выбор темы (`NoActionBar` / `ActionBar`), ориентации экрана, режима клавиатуры (`adjustResize` / `adjustPan`), цветов статус-бара и навбара, `Fullscreen`, `Immersive Sticky Mode`, поддержка выреза камеры (`SHORT_EDGES`), `FLAG_KEEP_SCREEN_ON`, `FLAG_SECURE`, `hardwareAccelerated` и `usesCleartextTraffic`.
- **Движок View и WebView:** режим встроенного `WebView` или системного выбора приложения (`Chooser`), настройка `User-Agent` (со снятием метки `; wv` для корректной работы OAuth), кэширования, `Mixed Content`, удалённой отладки (`chrome://inspect`), `<input type="file">`, `DownloadManager` и перехвата внешних схем (`tel:`, `tg:`, `whatsapp:` и др.).
- **Нативный JS Bridge (`window.AndroidBridge`):** встроенные методы `vibrate`, `showToast`, `copyToClipboard`, `shareText`, `setStatusBarColor`, `exitApp` для вызова нативных функций Android прямо из JavaScript.
- **Системные интеграции:** настройка `Deep Links` (кастомная схема и HTTPS-домен), приём данных из меню «Поделиться» (`ACTION_SEND`), регистрация приложения как браузера или лаунчера.
- **Разрешения (`uses-permission`):** гибкий выбор системных прав по пресетам или вручную, включая ввод кастомных разрешений.

### 2. `index.html` — HTML to APK Builder & Signer
Финальный упаковщик и подписант, который превращает базовый шаблон в готовое к установке приложение:
- **Упаковка веб-ресурсов:** внедрение HTML, CSS, JS и медиафайлов в `assets/www/` (одиночный `.html` файл автоматически сохраняется как `index.html`).
- **Редактор манифеста и ресурсов:** изменение названия приложения, `Package Name` (с синхронным патчем `resources.arsc`), `versionCode` / `versionName`, редактирование тегов `<meta-data>` и точечное включение/отключение разрешений из шаблона.
- **Автонарезка иконок:** конвертация загруженного изображения в форматы `PNG` и `WebP` (`192×192`) с подменой ресурсов лаунчера в `res/`.
- **Загрузка по ссылкам и пресеты:** каждый ресурс (шаблон, веб-файлы, иконку, текстовые поля, схему подписи и ключи) можно загружать как локально, так и по прямым URL или ссылкам GitHub (`/blob/`, `/raw/`). Поддерживается сохранение и импорт всех настроек проекта через единый **`config.json`**.
- **Zipalign и криптография:** 4-байтовое выравнивание несжатых записей (`zipalign`) и подпись APK схемами **`v1` (JAR)**, **`v2` (APK Signature Scheme v2)** или **`v1 + v2`** с автогенерацией ключей `RSA-2048` (с возможностью скачать `private.pem` и `cert.pem` для последующих обновлений) или загрузкой собственных сертификатов.

## 🚀 Порядок работы

1. Откройте **`golem generator.html`**, настройте параметры оболочки, выберите нужные разрешения и скачайте базовый `template.apk`.
2. Откройте **`index.html`**, загрузите скачанный `template.apk`, добавьте ваши HTML/CSS/JS файлы и иконку.
3. Проверьте параметры пакета, выберите схему подписи (`v1 + v2`) и нажмите **«🚀 Собрать и подписать APK»**.
4. Установите готовый `.apk` на Android-устройство.
