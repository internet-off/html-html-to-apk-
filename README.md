### 🧪 Что нового в тестовой версии (v12):
* **Подпись APK v1 и v2:** добавлен выбор схемы подписи (`v1 + v2`, только `v1` или только `v2` для современных версий Android).
* **Свои ключи (.pem):** появилась возможность загружать собственный приватный ключ и сертификат (файлом или по URL), а также скачивать сгенерированные ключи для будущих обновлений приложения.
* **Загрузка по ссылке:** базовый `template.apk` теперь можно подтянуть напрямую по ссылке из GitHub.
* **Улучшенная упаковка и иконки:** добавлено 4-байтовое выравнивание (`zipalign`), корректная подмена PNG/WebP иконок и патч имени приложения в `AndroidManifest.xml`.
